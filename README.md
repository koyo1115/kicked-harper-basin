# キックドハーパー写像 盆地図

## 概要
大学の研究で使用していたキックドハーパー写像のシミュレーションをWebアプリ化したものです。
パラメータをリアルタイムに変更しながら、出口盆地構造を可視化できます。

## デモ
https://kicked-harper-basin-c5pnhpnqn6tcyx4t4trvhd.streamlit.app

## 使い方
1. K・Lのパラメータをスライダーまたは直接入力で設定
2. 出口の位置・半径を設定
3. 「実行」ボタンを押すと盆地図が表示される

## 使用技術
- Python
- NumPy（数値計算）
- Matplotlib（グラフ描画）
- Streamlit（Webアプリ化）

## 開発背景
大学の卒業研究でJuliaを用いて実装したシミュレーションをPythonに移植し、
誰でもブラウザから操作できるWebアプリとして公開しました。
